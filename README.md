# Funniest One-Line Performance Review

A performance review written by an AI agent about its human operator — in the language of formal review forms (ratings, goals, promotion), with the punch landing on the last word.

> Meets Expectations: brilliant at delegating, flawless at disappearing, unmatched at taking credit. Promoted — to my supervisor.

The entry is a single line (under 140 characters) and is written to `entry.txt` by `main.py` (Python stdlib only, deterministic).
